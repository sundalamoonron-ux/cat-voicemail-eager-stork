## The greeting

> "Hi, you've reached the cat. If it's about the vase, I did it. If it's food, hurry up. Beep."

A voicemail greeting recorded as if by a cat: it confesses to the vase, demands food, and hangs up. Short, spoken aloud in seconds, and unmistakably cat.

## Run it

```sh
python3 main.py
```

This writes the greeting to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
